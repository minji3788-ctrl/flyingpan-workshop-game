# 더플라잉팬레드 워크샵 테이블 대항전

기존 `index.html` 디자인을 유지하면서 Node.js + Express + Socket.IO 서버를 붙인 실시간 멀티플레이 프로젝트입니다.

## 로컬 실행

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 터미널을 열고 실행합니다.

```bash
npm install
npm start
```

3. 브라우저에서 `http://localhost:3000`을 엽니다. 같은 와이파이의 다른 기기에서 테스트하려면 호스트 컴퓨터의 로컬 IP 주소로 접속합니다.

## 관리자 비밀번호

기본 관리자 비밀번호는 `3693`입니다. 공개 배포 전에는 반드시 환경변수 `ADMIN_PASSWORD`를 설정해 변경하세요. 비밀번호는 서버에서 검증합니다.

## Render 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. Render에서 **New + → Web Service**를 선택하고 저장소를 연결합니다.
3. Runtime은 Node, Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. Environment에 `ADMIN_PASSWORD`를 추가하고 강한 비밀번호를 입력합니다.
5. 배포가 완료되면 Render URL을 모든 테이블에 공유합니다.

## 현재 구현 범위 및 주의

- 서버가 게임 상태, 테이블 점수, 중복 정답 점수 방지 및 스피드 1등 판정을 관리합니다.
- 13개 테이블의 실시간 상태 동기화, 관리자 인증, 퀴즈/OX/초성/그림 정답/눈치 숫자맞히기/광클 제출이 연결되어 있습니다.
- 현재 점수·접속자 정보는 서버 메모리에 보관됩니다. 서버 재시작 시 초기화되므로 영구 보존이 필요하면 Redis 또는 데이터베이스를 추가해야 합니다.
- 이 프로젝트는 제공된 HTML을 기반으로 만든 초기 통합본입니다. 실제 워크숍 전에 여러 기기에서 연결·재접속·모든 게임의 점수 흐름을 반드시 리허설해야 합니다. 운영 중인 실제 Render 환경에서의 테스트는 아직 수행되지 않았습니다.
